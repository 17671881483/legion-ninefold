# 军团战争 · Web 九倍

浏览器单机玩法：一名玩家与三名 AI 队友对抗四名 AI，八路同时战斗、漏怪行军、守军返门协防与共享国王。界面保留经典 WC3 分区。

本轮使用用户指定的 5.0dJF 静态解析结果：24 个基础兵及 25 个直接升级、24 种木怪、35 波。原文件是默认三倍的历史地图；九倍、10 工人和30级科技是此 Web 的组合规则，未核定15A2原生九倍。

## 本地启动

无需安装依赖或构建：

```sh
cd /Users/a1/code/study/legion-ninefold/dist
/Users/a1/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 -m http.server 4173 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4173>，按 Ctrl+C 停止服务。

## 操作

- 新局300金、97木。先选择兵种，再点击己方6×8建造格；选中已有单位可升级或出售。出售返还累计投入的80%。
- 新随机池按原脚本六档各选一个兵种；24个基础兵是历史完整随机池的选取子集，升级分支以收录的25个直接升级为限。
- 小精灵最多10个、伐木最高30级；备战、战斗和暂停时均可下达训练／研究指令。小精灵固定50金、20秒，最多3个串行训练任务；科技同时消耗金和木，独立研究1项。开始时扣费，完成后才增加工人／科技等级，排队工人预留人口并计入10人上限。暂停冻结进度、倍速按比例加快，换波和存档不清空任务。
- “进攻”页有24种木怪：初级开局开放，高级在第10／15波开战时开放。库存与补货间隔各不相同，初级通常3只、冰魔2只，后期2只或1只。库存、CD条和剩余秒数常驻显示。
- 发木购买一次派一只并增加永久收入。备战购买用于即将开始的波次，战斗中购买用于下一波；开战时从随机起点轮询分配敌方四路，木怪不乘九。
- 国王强化每次80木并增加3收入，生命／攻击／恢复上限20／30／20级。每人可治疗一次、全队四次，每次回复10000生命、同队间隔2秒；满血不消耗。每完成4波增加2护甲和累计10%攻速。
- 首波备战80秒；后续普通波为40＋即将开始波次整除2秒；31波前60秒，32—35波前50秒。可提前点击开始。
- 普通波1—30以历史三倍数量×3适配九倍，10／20／30及31—35特殊波独立计数。首波108只，第三波120只；10／20／30各3只首领。
- 空格开战／暂停；1×／2×／4×控制模拟；T干扰、H治疗、Esc取消。拖动／WASD／方向键平移，滚轮缩放；小地图和玩家列表可定位，“路线”显示出怪与汇流。
- 对局自动保存在当前浏览器；旧存档保留旧兵种和已购买的待发木怪，开始新局使用新随机池。清理浏览器数据会删除存档。

## 科技价格与时间

1—8级使用R003：第n级花费金、木各60＋20×(n−1)，耗时18＋2×(n−1)秒。9—15级使用R00H：第n级花费金、木各200＋10×(n−9)，耗时35秒。16—30级按高级曲线延伸，金木各270至410、耗时35秒；这些级别明确属于Web延伸。工人每个50金、没有按数量递增。

原图军力门槛由用户的“随时可升级”要求覆盖。当前产木仍采用Web连续生产公式，只使用已经完成的工人和等级；没有把脚本反作弊8秒检查当作采集周期。

## 资料与适配

`dist/map-reference.js` 是生成后的参考数据；`reference/map-source.json` 保留这次使用的原始片段、rawcode、脚本与源文件哈希。可用 `scripts/import-map-reference.py` 重建；具体命令见脚本帮助。

物编HP、护甲、武器基础值与骰子均值供本Web模拟使用，不混用realHP、realdef或陈旧显示伤害。兵种价格／人口／升级取建造形态，战斗属性取对应战斗形态。只适配能够解释的部分技能，保留其余技能元数据。条件目标暴击不泛化；回复光环取最高值，王区战斗同样计算增伤／护甲／减速光环。旧54个Web兵种仅服务旧存档，4位英雄仍为Web设计。

普通系统怪生命×0.25、伤害×0.20；首领与木怪独立。国王基础生命／攻击与生命强化、伐木产速与16—30级科技费用延伸、6×8格数、碰撞和100秒狂暴仍为Web参数。31波后的连续加时、10／20波竞技场及最终Boss复活未照搬，目前仍分35轮守王。伤害克制取地图Misc配置，基础赏金取JASS／单位等级；GG动态赏金折扣暂不模拟。

更多证据与边界见 [RECONSTRUCTION.md](RECONSTRUCTION.md)、地图路径见 [MAP_EVIDENCE.md](MAP_EVIDENCE.md)。画面由Canvas／SVG绘制，未打包魔兽模型或贴图。本地模拟不提供联网、11平台账号或战绩同步。
