依据本地《军团战争v14.1A5_九倍怪物模式_解析数据包》开发的浏览器4v4模拟。平台地图ID `20197574`，地图SHA-256 `E079EE0D558552990882FACC4E6F371241A8CA23CFAA272772ABF9B3259FFDB1`。内部“军团战争8.2b”为遗留标题；本版新局使用v14.1A5数据，不混入5.0dJF配置。

在线游戏：[军团战争](https://legion-ninefold-web.creamysage6.chatgpt.site/)。源码位于 `/Users/a1/code/study/legion-ninefold`，GitHub远端为 `github`。无需第三方依赖；Node运行 `npm test`。用任意静态HTTP服务器托管 `dist/`，浏览器打开首页游玩。不能用file协议直接加载ES模块。

修改代码、样式或生成数据后运行 `npm run build`，为入口、样式及全部ES模块生成内容版本，避免浏览器混用旧英雄数据与新界面。`npm run data:rebuild`会自动更新这些版本；`node scripts/stamp-assets.mjs --check`可核对当前版本是否一致。

## 九倍规则

开局500金、94木。小精灵预付50金、12秒，普通玩家上限10；原图训练开始的返费表达式在正金币费用时即使没有免费券也返还，Web按已核定的e003训练钩子保留这个源行为。科技为R003七级与R00H二十三级，共30级，逐级扣金木并计时，满足来源兵力门槛后生效。工人和研究独立队列运行，暂停、倍速、刷新保留进度。采木采用实际JASS的连续平均映射：每工人每10秒 `2＋基础科技等级＋2.5×高级科技等级`；高级物编字段每级+2单独保留，不能据此覆盖脚本。

第6—10波的合格SAPPER系统怪生命×1.5，第11波起×3，排除建筑/召唤/巨型；31波机械不吃该倍率。波次表已应用倍率。6—28波除10/20外有10%下一波替换；原脚本在每批出怪前抽一次，同批各路结果一致，边际概率为10%。替换怪仍使用当前波创建钩子，击杀额外+3金。

第11波起发兵收入按单位points整数除2；国王强化100木、独立增加4收入。国王生命/攻击/恢复早期上限20/30/20，攻击/恢复第16波、生命第17波解除为60/80/60。治疗按最大生命50%计算。生命科技超原生静态有效等级的部分使用明确Web映射，详见还原说明。

第11波起首次漏怪触发该队全员各扣1000木。原脚本两队无漏奖励均检查同一队标志、国王击杀池存在双边入账；本版保留可定位的脚本行为，说明文本不冒充正确实现。系统怪金币读取Ie[Dg]，发兵怪金币读取单位等级；跨线和漏怪按对应来源分支结算。

## 操作与用户指定规则

选择建造者、选择兵种，再点击自己的格子。军团新建、升级和形态转换按来源时间施工；按此前用户要求，手动或自动开波时所有已付款的军团施工立即完成并参与当波。工人、科技、农场不会因开波快进，也不重复扣费。

在“建造”页点击“英雄”，选择祭坛并放在自己的空格；祭坛完成后点击其选择按钮召唤英雄，再逐级升级。九倍脚本允许每局两座祭坛，英雄类型不得重复，施工中的选择也占用名额。12个常规分支有11级，另外5个特殊分支保留各自3阶段与来源人口；英雄和祭坛不能出售。变形建造者不能选择地狱咆哮；炼金术士需要完成发条地精与地精伐木机，解锁记录出售后保留。祭坛缺失原生价格字段，当前Web按0金、0木、0人口与1秒施工接入；没有套用旧版军力门槛。

战斗中按T或点击“T怪”再点地图。A050防卡兵作用半径200原始坐标（Web逻辑2/3），每人独立5秒冷却，空点也消耗冷却。清除圆内双方已出场怪物的当前目标、追击路径与未出手攻击，再向各自王区进攻；不眩晕、不额外延后攻击CD。橙色短条显示抬手，T可以实际取消；已结算伤害不回滚。Esc取消选点。

拖动/WASD/方向键移动镜头、滚轮/双指缩放；小地图和玩家列表定位。空格开波/暂停、H治疗国王。造位、行走距离、清线与传送协防共同影响战局。

## 测试沙盒

首页选择“测试沙盒”进入，右上角“测试沙盒”打开控制台。开局10万金、10万木、300人口；备战不限时，手动开始所选的1—35波。默认关闭AI、仅自己的第1路刷新系统怪；开启AI后恢复八路模拟。关闭AI保留已有AI军团和已付款经济任务，停止自动决策。

控制台支持免费切换建造者并保留现有军团、补足资源、一键完成自己的已付款施工/招募/研究、清空自己的阵容，以及随时中止战斗返回布阵。“训练礼物测试”明确赠予一组含训练的礼物，普通局仍按第6/13波实际结算发放。测试资格可单独开启超级赞助，或开关80项已登记来源资格；仅模拟本地沙盒状态并随存档保存，不关联平台账号，不跳过配方完成记录和数量限制。重置或切换波次会清除当前怪物、发兵队列和技能任务，恢复双方国王及治疗次数，保留阵容、资源与经济任务进度。兵种来源条件、升级路径和战斗规则继续生效。

每次只测试选定一波，清波后回到同一波备战；不自动进入竞技场，也不叠加31—35连续波，不结算过波奖励。沙盒发兵仅限布阵期，参与本次手动测试；战斗中的击杀收益、漏怪惩罚和资源消耗仍会保留。沙盒使用独立存档槽，控制台“模式选择与存档”可切换并继续普通对局；普通模式不能执行沙盒指令。

## 实现边界

这是Canvas/SVG本地AI模拟，没有打包魔兽模型/贴图/音频，也没有平台联网、账号特权或付费校验。英雄入口使用本版JASS分页，成长链按本版连续Mk/Ml映射与编号阶段重建；缺失的原生菜单条件没有借用5.0dJF。未选英雄的祭坛在普通战斗中不参战；提示所述竞技随机变身尚缺转换来源，目前同样跳过空祭坛。技能、资格与默认字段的未核定部分逐项标记；这不是全技能完成的复刻。

彩蛋合成、普通升级和外观映射按修订文档分别接入：383条文档记录中，107条基础兵种、144条普通升级、32条确认彩蛋、2条待核定彩蛋、1条彩蛋后续升级、73条外观、16条权益变体、6条变形入口及2条入口待确认。英雄新增阶段保持独立类别。图鉴可按分类筛选，并分别显示实际升级来源、对应本体类别和使用条件；紫色表示外观／权益，不表示彩蛋。

确认配方在军团施工完成时记录历史，出售后仍保留；未完工不计。首波角鹰、首次同时5只木乃伊、沙虫完成数差值与账号资格各自判定，附加兵种不作为消耗材料。兽王萨尔与霜狼杜隆坦统一展示并按同一历史前置处理。圣龙本体与外观共用当前1个名额，施工也预留。R00L/R00M的完整路径仍待核定，保持明确提示；兽王击杀记录不擅自选择101或166的冲突门槛。

修订来源快照为 `reference/document-catalog-reviewed.json`，运行 `npm run data:document` 可重建分类覆盖层。原始物编数值、单位代码与技能证据保持不变。旧存档只补当前可证明的完成历史，无法追溯此前未记录且已出售的单位。

第5波藏宝猎人有60秒持续时间，全局首杀和末杀分别奖励80金、150木；其他击杀不领取普通波次赏金。第7—19波宝藏怪死亡后，奖励归原路线玩家，选择金币、木材、国王永久护甲或己方军团建筑永久护甲；第10/14波提升档位，第14波起可选择立即免费提升1级伐木。奖励可以保留、每份只能领取一次，AI也会领取。军团护甲随建筑升级和存档保留，从下次普通战或竞技出战生效。

娜迦农夫从开工时提供玩家级15%击杀额外1金币概率，额外每座+0.5个百分点；升级完工注销，出售按源脚本保留概率。每座存活娜迦农场主在回合结算时获得3倍本波农夫数的金币，保留原型农夫尸体也被计入的源条件。电锯王的A0LM在普通怪击杀分支有35%获得1木，飞行奖励分支及31波后排除。

图鉴还包含14种特殊怪物、114项物品与815项科技的完整来源记录。物品和科技对象表本身不证明全部购买/研究入口，查阅资料与已确认玩法入口分别保留。三档彩蛋献祭奖励已保留，但数据包没有A1U4/A1U5/A1U6携带单位或授予路径，尚未任意开放献祭。

运行 `node scripts/content-coverage.mjs --write` 可更新 [内容覆盖清单](reference/content-coverage.json)。当前534个玩家阶段对象连同运行时形态、召唤物及脚本注入能力涉及624种不同技能：407种已实现、42种部分实现、34种状态标记、141种仍待核定；连同木怪、波次和特殊怪，仍有162种技能待核定及42种部分实现。本次继续补入巨魔狂战士斧头/鲁莽/保命监听、吉安娜四项冰系技能、克尔苏加德锁链/死亡凋零/新星自伤/裂隙及护命匣召唤。原生命令技能手动与自动共用冷却；伊瑟拉和炼金术士的直接脚本自动冷却仍独立。旧存档恢复时重编译技能定义并保留冷却、魔法、增益和动态注入。这个目标仍在推进，不能将数据完整导入等同为机制完美还原。

详细来源、规则冲突和验证记录见 [RECONSTRUCTION.md](RECONSTRUCTION.md)。
