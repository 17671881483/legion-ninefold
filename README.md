# 军团战争 · 5.0dJF

依据《军团战争5.0dJF_兵种怪物技能数据.xlsx》与其引用的SLK、TXT、W3A、JASS，制作可在浏览器运行的4v4本地模拟。你与3名AI队友对抗4名AI。按用户最新要求，文档配置优先于此前的九倍、10工人、30科技等手动要求；默认三倍、7工人、15级科技。旧Web全局干扰与100秒狂暴缺少来源证据，已默认关闭。

## 运行

无需安装第三方依赖，使用Node 18+运行 `npm test`。用任意静态HTTP服务器托管 `dist/`，打开首页即可游玩。浏览器模块需经HTTP加载，不能双击HTML使用。

源码目录：`/Users/a1/code/study/legion-ninefold`。现有在线地址：<https://legion-ninefold-web.creamysage6.chatgpt.site/>。`.openai/hosting.json` 保留原Site身份与dist部署目录。

## 已接入的数据

- 17种AP建造者；各族使用自己的基础兵。先知每阶15选1、共6种；变形建造者使用6阶代理，施工完成后随机替换。
- 315条防守表记录中，313条有已确认静态获取路径：201个普通建筑阶段（含6变形代理）、110个英雄阶段、2个特殊形态。其余2个仅注册变体在图鉴标记入口未确认。阶段数不是独立兵种数。
- 10个英雄祭坛入口，各有11阶段升级链；新局取消此前4个自定义英雄。升级边保持源文件大小写，215条能解析；99条包含未解析的H0DC，不擅自修正或开放。
- 35波主配置直接使用表内每路数量，首波36，10/20/30波各3首领；不再额外乘3或9，不再削减普通怪生命和伤害。
- 24种进攻木怪，逐项使用来源价格、永久收入、库存、补货间隔与10/15波开放条件。
- 战斗技能按原生配置、武器字段及JASS分别编译，支持多技能、魔法、独立冷却、目标过滤、持续状态、范围／弹射、召唤、复活及脚本附伤。图鉴逐项显示执行状态、具体数值和未核定项。

## 玩法

开局选择建造者，点击兵种，再点击自己的格子建造。施工中显示倒计时；完成前不计军力、不出战。升级按目标配置额外支付金币和木材，完成后生效。军力取建筑points，区别于累计花费。

小精灵固定50金、20秒，军力350解锁，上限7。科技共15级、支付金木并满足已核定门槛；工人和科技分通道进行，完成后生效。1—8级使用R003，9—15级使用R00H；后者部分前置字段继承不明确，原始值保留，未猜测出额外封锁条件。

开局300金、97木、15人口（主城7＋预置农场8），人口上限300。农场24金＋80木、5秒、增加8人口。采木依A09C/Awha的10秒采集量折算为连续平均产速，每工人采集量为2＋基础科技级＋2×高级科技级。这是物编的Web映射，未经魔兽引擎运行验证。

先知预言和更换种族各5次，费用递增。换族支付后从随机两个建造者中选择；祭坛英雄占用后锁定换族。出售按当前建筑points及来源分档：同回合新建100%，通常50%，奴仆/苦工75%，螯虾分支90%。缺失基础费用的研究采用显式缺省映射，见还原说明。

第10、20波后进入30秒竞技准备，军团竞技最长120秒；胜方每人波次×10金币，平手双方每人波次×5。竞技结束后20秒过渡、再准备30秒。第31波起保留存活军团与残怪，每50秒叠加下一波；第35波停止推进，最终首领死亡后再生成，击倒国王才结束。

拖动／WASD／方向键平移，滚轮缩放，手机双指缩放。小地图与玩家列表可定位；空格开战／暂停，H治疗，Esc取消部署。1×／2×／4×影响所有模拟进度。

## 图鉴与来源边界

顶部“眼睛”按钮和建造栏“兵种图鉴”可检索315条防守记录、24木怪、35波怪物，查看技能、金木费用、人口、升级链、原始代码和工作簿行号。参与模拟、状态标记、待核定分别显示，不把仅存档的原始字段算作生效技能。

当前少数Lightning Attack基础表现技能缺少闭合的独立效果证据，保留待核定，不叠加臆造伤害；对应武器的普通攻击、溅射或穿透仍独立运行。国王在特定波次动态获取随机技能的脚本链尚未接入；本版已关闭旧版无来源的国王额外范围砍。两个仅注册变体、精确H0DC升级目标与部分魔兽缺省字段不能靠猜测补齐。资料来自5.0dJF，不是15A2或当前11平台九倍版本的验证。

完整数据与证据在 `reference/workbook-source.json`，生成器 `scripts/import-workbook.py` 可脱离另一聊天目录、直接从快照重建浏览器数据。原始历史地图快照与生成器仍保留用于追溯。详见 [RECONSTRUCTION.md](RECONSTRUCTION.md)、[MAP_EVIDENCE.md](MAP_EVIDENCE.md)。

旧局迁移前会备份一份浏览器本地快照；旧兵种定义继续保留。清理浏览器数据会同时删除存档和备份。画面使用Canvas／SVG，没有打包魔兽模型或贴图，也不提供平台账号、联网对战或战绩同步。
