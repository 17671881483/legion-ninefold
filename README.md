# 军团战争 · 九倍怪物 Web 复刻

这是一个可在浏览器完成整场对局的本地游戏：你与三名 AI 队友对抗四名 AI 对手，双方各四路，共 35 波。每名玩家有独立的 6×8 格建造区，兵种和怪物实际移动、寻敌与战斗，由阵营共享国王守住最后防线。

地图参考可核查的历史军团地图：两队左右并排，每队四个防区按 2×2 排列；北侧怪向南、南侧怪向北进入公共横廊，再汇入中央纵道攻王。漏怪连续移动，守军则经过返出生门、等待源路清空、传送王前协防的流程。地图比例、格数和寻敌范围采用 Web 配置，具体依据见 [MAP_EVIDENCE.md](MAP_EVIDENCE.md)。

该实现参考 11 平台《军团战争》的公开资料及九倍玩法社区讨论。目标版本线索为用户提供的“15A2”，尚未核定地图文件与数值。Web 中的兵种价格、波次、倍率基准和经济节奏均为独立调校，不能作为原版数值资料。

## 启动

无需安装 npm 包，也无需构建。用本机随 Codex 提供的 Python 启动静态服务：

```sh
cd /Users/a1/code/study/legion-ninefold/dist
/Users/a1/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 -m http.server 4173 --bind 127.0.0.1
```

在浏览器打开 <http://127.0.0.1:4173>。终端按 `Ctrl+C` 停止服务。其他电脑可以使用自己的 Python 3，在 `dist` 目录运行同样的 `-m http.server 4173 --bind 127.0.0.1` 参数。

## 操作

- 界面采用经典 WC3 布局：顶部资源、右上战况、左下小地图、中下肖像与属性、右下指令。当前选中对象决定可执行操作。
- 在“建造”面板选择兵种，点击己方建造格放置；选中已有兵种可查看信息、升级或出售。
- 小精灵最多 10 个，伐木科技最高 30 级；备战和战斗期间均可随时招募、升级，暂停时也可操作。费用扣除后，新的产木效率立即生效。按钮显示当前数量／等级及上限。
- 初始人口上限 40；“扩建营地”花费 75 金币增加 20 人口，最高 160。工人、建筑和英雄都会占人口。
- 在“进攻”面板花费木材向敌方派怪。每种木怪最多缓存 3 只，解锁时满库存；消耗后按各自 CD 逐只补充，连续购买不重置正在恢复的进度。库存、补充进度条及剩余秒数始终显示，木材不足也能查看；暂停与倍速作用于补充时间。在“国王”面板进行团队防御操作。
- 国王治疗每名玩家每局一次，全队共四次，每次回复生命上限的 30%；满血不会消耗次数。
- “开始波次”推进准备阶段。暂停和 `1× / 2× / 4×` 控制模拟速度。
- “战场全景 / 我的战区 / 国王防线”切换镜头；“路线”显示出怪与汇流路径。拖动、`WASD` 或方向键平移，滚轮缩放；玩家列表和小地图也可定位。
- `Esc` 取消当前选择，`Space` 开战或暂停，`T` 干扰，`H` 治疗。技能须满足界面显示的资源、次数及冷却条件。
- “军团手册”可查看操作、波次图鉴和复刻说明。先保住当前波，再在造兵、伐木科技和进攻之间分配资源。
- 对局自动保存在当前浏览器本地存储中，刷新后可从欢迎页继续；清理浏览器数据会删除存档。

## 实现与验收范围

本版本的可玩范围包括：

1. 八路与两名共享国王同时参与模拟，七名 AI 会发展、防守和进攻。
2. 建造、升级、出售、科技、派怪及国王操作实际影响资源和战斗。
3. 35 波推进包含漏怪汇流、守军王前协防、国王受伤和胜负结算，可重新开始一局。
4. 全景可看到各路移动和交战，镜头操作、暂停和倍速保持一致。
5. 可以通过浏览器完成玩家操作闭环；页面不是玩法说明或单路战斗演示。

普通系统怪数量按本 Web 基数乘九；实际生命为波表生命的 0.25 倍、伤害为 0.20 倍，Boss 和派出的木怪不作这两项缩放。默认关闭人工“130”拥挤增益。这些是维持本 Web 对局节奏的独立设计，原版九倍的参照基准仍未核定。

已通过 33 组引擎测试及 10 组地图测试（340 个坐标／导航样本）。标准难度、seed 42 的完整 AI 对局在第 29 波由联盟获胜，历时 3412.0 模拟秒，峰值 1545 个实体；未出现负资源、超人口或死亡实体残留。浏览器验证覆盖建造／升级／出售、发木、存档恢复、路线显示和四种视口布局；另验证木怪 3 连购与补充、暂停／4 倍速、刷新续档及桌面／短屏／手机 CD 可见性；小精灵 10 个／科技 30 级上下限、战斗期间招募升级及即时产木、满级续档与电脑／手机显示均通过验证；这些结果验证本 Web 实现，不代表已核定 15A2。

当前为单机模拟，不提供多人联网、11 平台账号或战绩同步。场景、单位形象和图标由 Canvas／SVG 程序绘制，未打包魔兽原版模型与贴图。更多对应关系和资料适用范围见 [RECONSTRUCTION.md](RECONSTRUCTION.md)。
