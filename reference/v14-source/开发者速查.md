# 军团战争 v14.1A5 九倍模式开发者速查

## 推荐的数据连接方式

| 目标 | 主表 | 连接键 |
|---|---|---|
| 玩家兵种属性/价格 | `player_buildable_units.csv` | `rawcode` |
| 兵种技能 | `player_unit_abilities.csv` | `unit_rawcode → rawcode` |
| 升级/合成路线 | `unit_upgrade_edges.csv` | `source_rawcode / target_rawcode` |
| 合成资格与科技 | `unit_upgrade_requirements.csv` | `target_rawcode` |
| 发兵数据 | `sent_units.csv` | `rawcode` |
| 彩蛋条件分支 | `easter_egg_recipes.csv` | `source_rawcode / target_rawcode` |
| 彩蛋图鉴与菜单 | `easter_egg_catalog.csv`、`easter_egg_menu_tree.csv` | `catalog_ability_rawcode / node_ability_rawcode` |
| 波次和实际击杀金币 | `waves_x9.csv`、`wave_kill_gold.csv` | `wave` |

不要用中文名称做唯一键；同名变体很多，rawcode 大小写也必须保留。

## 九倍模式关键经济

- 小精灵 `e003`：50金、建造12秒、`reptm=16`秒、占1人口、120生命；普通非特权玩家在九倍模式最多10个。
- 伐木科技 `R003` 1—7级：金币 `80 + 20×(等级-1)`，木材 `40 + 10×(等级-1)`，时间 `12 + 4×(等级-1)` 秒，每级采伐 +1。
- 伐木科技 `R00H` 对应总等级8—30：每级200金、200木、38秒，每级采伐 +2；总等级30时累计采伐加成 +53。
- 第 11 波起，发兵提供的收入按单位点数整数除以2。
- 系统怪单只基础击杀金币（1—35波）：

```text
3,3,4,5,5,5,6,6,5,51,5,6,7,12,9,8,10,8,10,86,20,20,11,11,27,36,48,49,14,164,0,0,0,0,0
```

- 第6—28波中除第10/20波外，每只怪有10%概率替换成下一波怪，击杀时在本波基础金币上再加3。
- 怪物漏到中路后按原路线的赏金比例缩减；国王击杀进入队伍金币池并在回合末平分。
- 单位对象的 `bounty*` 只作底层参考，不能代替 `wave_kill_gold.csv`。

## 彩蛋/合成判读

`easter_egg_recipes.csv` 的核心判据是：完整升级树存在该边，但普通即时选择表没有，或目标文本明确写了“彩蛋”。这比根据名字猜测稳定，但仍需结合以下字段：

- `requirement_rawcodes/requirement_names`：解锁科技、兵力门槛、会员/赞助或其他资格。
- `target_gold_cost`：本次合成/升级价格，不是整条路线累计价格。
- `target_total_power_points`：合成后对象的总兵力值。
- `target_in_easter_catalog`：目标是否在图鉴菜单中。
- `not_in_immediate_select_table`：是否属于条件/隐藏分支。

`explicit_easter_egg_units.csv` 包含预览和浏览页对象；只有结合升级图、图鉴登记和需求后，才能判断局内是否实际可建。

## 实现时的注意事项

- `gold_cost` 是当前对象价格，`total_power_points` 是总兵力；不要混用。
- DPS 是对象平均伤害除以攻击间隔，未计算护甲、技能、前摇、溅射与目标切换。
- 技能先看 `player_unit_abilities.csv`，九倍模式脚本覆盖再看 `x9_scripted_skills.csv`。
- 需求有多个时应全部保留，不要只取第一条。
- 平台账号资格、付费状态和服务端注入无法仅靠静态地图完整复现；表中已保留相关 rawcode，供你在新游戏里改造成自己的解锁系统。
